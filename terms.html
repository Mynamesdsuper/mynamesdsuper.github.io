Lyra (ContentFarm) — last updated 2026-08-22

Lyra is a personal, single-user desktop application for generating short-form lyric video edits from audio tracks. It runs locally on the user's own machine and is not offered as a hosted, multi-tenant web service.

1. Use of the application

Lyra is provided for personal, non-commercial use by its developer/user. The application is provided "as is", without warranty of any kind, express or implied.

2. Third-party integrations

Lyra can optionally connect to a TikTok account via TikTok's official OAuth Login Kit, at the user's explicit request. This connection is used to identify the connected account and, in a future release, to help the user publish their own rendered videos to their own TikTok account. Lyra only acts on the connected account when the user explicitly triggers an action inside the application.

3. Disconnecting

The user can disconnect their TikTok account at any time from within the application, which revokes the associated access token. Access can also be revoked directly from TikTok's own account settings.

These terms may be updated as the application evolves. Continued use of the application after a change constitutes acceptance of the updated terms.
